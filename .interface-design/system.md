# Design System — ПД-ИД

## Direction

**Personality:** Тёплая бумага + графитовые чернила («Utility & Function», сдвинутая в тёплый тон)
**Foundation:** warm-neutral (oklch, hue 75) — не холодный slate, потому что это личный
ежедневник, а не корпоративный дашборд
**Depth:** borders-only. Никаких decorative-теней; карточки отделяются тонкой границей
(border-neutral-200), не заливкой другого цвета

**Домен:** блокнот, пометка на полях, вечерний итог, входящий лоток, папка проекта.
**Сигнатура:** объяснение ИИ («Почему такой приоритет») оформлено как рукописная
пометка на полях — курсив, чернильный акцент, тонкая вертикальная черта слева.
Отличает «что написал пользователь» от «что заметил ИИ».

## Tokens

### Spacing

Base: 4px (Tailwind default scale, без изменений — уже было последовательно)

### Colors

Переопределены в `src/app/globals.css` через `@theme`:

```css
--color-neutral-50:  oklch(0.985 0.004 75);
--color-neutral-100: oklch(0.97  0.006 75);
--color-neutral-200: oklch(0.93  0.008 75);
--color-neutral-300: oklch(0.87  0.01  75);
--color-neutral-400: oklch(0.7   0.012 75);
--color-neutral-500: oklch(0.55  0.012 75);
--color-neutral-600: oklch(0.45  0.012 75);
--color-neutral-700: oklch(0.35  0.012 75);
--color-neutral-800: oklch(0.25  0.01  75);
--color-neutral-900: oklch(0.16  0.008 75);
--color-neutral-950: oklch(0.1   0.006 75);

--color-ink-50:  oklch(0.95 0.02 250);
--color-ink-500: oklch(0.42 0.09 250);
--color-ink-600: oklch(0.36 0.09 250);
```

Один акцент (ink-500/600) — используется только на фокус-кольце и в сигнатуре
«почему». Маркеры приоритета остаются семантическими и НЕ входят в тему:
`bg-red-500` (P0), `bg-amber-500` (P1), `bg-blue-400` (P2), `bg-neutral-400` (P3),
`bg-neutral-300` (Позже) — стандартная палитра Tailwind, не переопределялась.

### Radius

`rounded-lg` (8px) для карточек/полей — без изменений от исходной вёрстки.

### Typography

Шрифт: **Manrope** (`next/font/google`, subsets: latin + cyrillic), подключён как
`--font-manrope` → `--font-sans`. Единая гарнитура на всё приложение (без пары
serif/sans) — инструмент функциональный, не lifestyle-бренд, лишняя пара шрифтов
была бы избыточна.

## Patterns

- **Sidebar = фон холста + граница**, не отдельный белый блок (иначе шов между
  поверхностями). Тот же принцип для шапки: `bg-neutral-50`, не `bg-white`.
- **Карточки/поля ввода** — `bg-white` (единственная приподнятая поверхность),
  обычные секции — `bg-neutral-50`.
- **Пометка ИИ** («Почему», риск отложить): `italic text-ink-600 border-l-2
  border-ink-500/30 pl-2` — короткая фраза, не абзац.
- **Фокус-кольцо**: `outline: 2px solid var(--color-ink-500)` глобально через
  `:focus-visible` в globals.css — не нужно прописывать на каждом элементе отдельно.
- **Пустые секции не рендерятся** (например, пустой P0) — не показываем
  «здесь пусто» ради самого списка.

## Decisions

- 2026-08-24 — Направление выбрано как гибрид «Utility & Function» (спокойно,
  функционально) + тёплая температура вместо холодной slate, потому что продукт —
  личный инструмент, а не enterprise-дашборд. Подтверждено пользователем («попробуй»).
- 2026-08-24 — Один акцентный цвет (ink-blue), не несколько — чтобы не спорить
  с уже существующими семантическими маркерами приоритета.
- 2026-08-24 — Токены применены через переопределение `neutral-*` в Tailwind
  `@theme`, а не через точечную правку классов в каждом компоненте — все
  компоненты уже использовали `neutral-*` последовательно, что сделало
  глобальную замену безопасной и низкорисковой.
