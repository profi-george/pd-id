# Спецификация: ПД-ИД (План дня — Итог дня)

## 1. Что это и для кого
Личный веб-инструмент для ежедневного осознанного планирования и рефлексии по авторской методике «План дня — Итог дня». Один пользователь, без регистрации и логина.

Главное действие: **вечером подвести итог сегодняшнего дня и набросать черновик плана на завтра**; утром — быстро доработать этот черновик и начать работу в понятном порядке приоритетов, не тратя утренний ресурс на раздумья.

## 2. User stories

- [ядро] Как пользователь, я хочу завести список своих проектов, чтобы группировать по ним задачи.
- [ядро] Как пользователь, я хочу добавить задачу и оценить её по важности, срочности, энергозатратности и времени на выполнение, чтобы система посчитала приоритет и я знал, что делать первым.
- [ядро] Как пользователь, я хочу видеть план на сегодня, отсортированный по приоритету, с возможностью вручную поправить порядок.
- [ядро] Как пользователь, я хочу вечером в одной форме заполнить итог дня: по каждой задаче оценку 0–10, «почему получилось» / «почему не получилось», метрики дня (трудность, настроение, эффективность, переживания) и вывод на завтра.
- [ядро] Как пользователь, я хочу, чтобы невыполненные задачи сразу предлагались к переносу на завтра, чтобы ничего не терялось.
- [ядро] Как пользователь, я хочу, чтобы вечерняя форма итога сразу же формировала черновик плана на завтра (перенесённые + новые задачи), а утром я мог его быстро доработать.
- Как пользователь, я хочу держать бэклог задач/идей без даты, чтобы забирать из него нужное в план дня.
- Как пользователь, я хочу видеть короткую памятку о правильной формулировке задач (конкретно, через результат действия, не поверхностно) при добавлении задачи.
- Как пользователь, я хочу посмотреть историю прошлых дней (ПД+ИД), чтобы находить закономерности в своём состоянии и результатах.

## 3. Модель данных

### Проект
- название (текст)

### Задача
- текст задачи (текст)
- проект (связь на Проект, может быть без проекта)
- важность (число 1–5)
- срочность (число 1–5)
- энергозатратность (число 1–5)
- время на выполнение (число, в часах)
- приоритет (считается автоматически: важность + срочность; используется для сортировки — энергозатратность и время показываются рядом как справочная информация, порядок можно поправить вручную)
- дата, на которую запланирована (дата; пусто = задача в бэклоге)
- статус (выбор: в бэклоге / запланирована / выполнена / не выполнена / перенесена)
- оценка выполнения (число 0–10, заполняется вечером)

### День (запись Итога дня)
- дата (дата)
- почему получилось (текст)
- почему не получилось (текст)
- трудность дня (число 1–10)
- настроение (число 1–10)
- эффективность (число 1–10)
- переживания (число 1–10)
- вывод на завтра (текст)

Связи: у Проекта много Задач. У Дня много Задач (по совпадению даты). Задача без даты живёт в Бэклоге.

## 4. Экраны

- **Сегодня** — главный экран. Утром показывает план на день (список задач по убыванию приоритета, можно перетащить вручную). Вечером по кнопке «Подвести итог дня» открывается форма итога: оценки по каждой запланированной задаче, текстовые ответы, метрики дня, вывод на завтра. После сохранения итога сразу формируется черновик плана на завтра — невыполненные задачи предложены к переносу, можно добавить новые.
- **Бэклог** — задачи без даты, сгруппированы по проекту. Кнопка «добавить задачу» (с памяткой по формулировке), кнопка «запланировать на сегодня/завтра».
- **Проекты** — список проектов, добавление/переименование/удаление.
- **История** — список прошлых дней (ПД+ИД), карточка раскрывается в полную запись дня.

## 5. Стек и условия
- Платформа: веб-приложение
- Авторизация: нет, один пользователь
- Хранение данных: SQLite (через Prisma) — надёжно переживает перезапуск сервера
- Рекомендованный стек: Next.js + Prisma + SQLite

## 6. Этапы (MVP по шагам)

**Этап 1 — скелет (показать завтра):**
- Проекты: создание/редактирование/удаление
- Добавление задачи: текст (с памяткой-подсказкой по формулировке рядом с полем), проект, 4 параметра приоритета
- Бэклог: список задач без даты
- Экран «Сегодня»: план дня, авто-сортировка по приоритету, ручная перестановка
- Вечерняя форма «Итог дня»: оценка каждой задачи, «почему получилось/не получилось», метрики дня, вывод на завтра
- После сохранения итога — перенос невыполненных задач в черновик плана на завтра + возможность добавить новые

Сквозное действие: завёл проект → добавил задачи с приоритетами → увидел план на сегодня в правильном порядке → вечером заполнил итог → невыполненное само перенеслось на завтра.

**Этап 2:** История — архив прошлых дней, просмотр отдельных записей.

**Этап 3:** Лёгкая авто-подсказка проекта по ключевым словам в тексте задачи (без ИИ, простая эвристика); базовая статистика по метрикам дня (графики трендов).

**Этап 4 (далее):** полноценная ИИ-категоризация задач по проектам, напоминания/уведомления, экспорт данных, мобильная версия.
